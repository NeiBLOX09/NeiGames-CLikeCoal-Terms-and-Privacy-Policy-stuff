CLikeCoal Survival - Privacy Policy
Last updated: 20 October 2026
Developer: NeiGames
Contact: neigames.business@gmail.com

1. Summary
CLikeCoal Survival does not require an account and does not collect, sell or share personal information.

2. Information the game stores on your device
The game saves your progress, settings, achievements and endings in a local save file on your PC (in the game's own app data folder). This file never leaves your device unless you copy it yourself. Uninstalling the game removes it.

3. Information we collect
None. The game has no analytics, no advertising, no tracking and no user accounts.

4. Internet use
The game does not need an internet connection to be played. Some optional developer features can use the internet, and they are off for normal players:
- Developer notifications: only if a developer deliberately places a webhook address on that PC, the game can post a short message (for example that a rare color-variant character appeared, with the game minute, game mode and a screenshot) to the developer's own Discord channel. Without that file nothing is sent.
- Color-variant codes: when you finish the game with a rare color-variant, the game shows a one-time code and QR code on the screen. The code is created and shown on your device. It is only used if you choose to scan or enter it in the separate NeiGames Bank app.

5. Children
The game is a horror game and is not intended for young children. We do not knowingly collect information from anyone, including children.

6. Third parties
The game does not include third-party advertising or analytics. If you download or buy the game, the Microsoft Store processes your purchase under Microsoft's own privacy statement.

7. Changes
If this policy changes, the new version will be published at the same web address with a new date.
